# scoop-bbctl

Scoop bucket for `bbctl` — Blackbuck's gated EC2 access CLI.

## Install

```powershell
scoop bucket add bbctl https://github.com/Blackbuck-LABS/scoop-bbctl
scoop install bbctl
```

Manifests in `bucket/` are published automatically by GoReleaser on every
`bbctl` release — do not edit them by hand.
